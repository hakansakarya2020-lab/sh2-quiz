# SH2 Quiz

Canlı quiz ve sınav platformu. Hocalar kendi hesaplarıyla test kütüphanesi oluşturur, sınavı QR kod + PIN ile başlatır; katılımcılar telefondan hesapsız bağlanır. Sonuçlar Firebase Firestore'da saklanır.

- Site: `public/` (statik HTML/JS, derleme gerekmez)
- Güvenlik kuralları: `firestore.rules`
- Kurulum: `KURULUM.md`
